# Stage 3 UART通信测试指南

## 📋 测试概述

Stage 3 测试验证UART通信功能，包括：
- 设备打开/关闭
- 数据包发送/接收
- 超时处理机制
- 实际与DS532模块通信

## ⚠️ 重要前提条件

### 硬件要求
1. **DS532指纹模块**: 正确连接到开发板
2. **UART连接**: DS532连接到UART6 (/dev/ttymxc5)
3. **电源供应**: DS532模块正常供电
4. **接线检查**: 确保TX/RX/GND连接正确

### 软件要求
1. **驱动加载**: DS532驱动已正确加载
2. **设备节点**: /dev/ds532_fp 存在且权限正确
3. **TTY配置**: UART6配置为57600 8N1

## 🚀 快速开始

### 1. 准备环境

```bash
# 加载驱动
insmod /root/smart_lock/driver/ds532_driver.ko

# 检查设备节点
ls -l /dev/ds532_fp

# 配置TTY（如果需要）
stty -F /dev/ttymxc5 57600 cs8 -cstopb -parenb raw

# 查看内核日志
dmesg | grep DS532 | tail -10
```

### 2. 编译测试程序

```bash
cd kiro_source/user
make stage3_uart_test
```

### 3. 运行测试

```bash
./stage3_uart_test
```

## 📊 测试内容详解

### 测试1: 设备打开/关闭
- **目的**: 验证字符设备的基本操作
- **测试项**:
  - 成功打开 /dev/ds532_fp
  - 正确关闭设备
  - 文件描述符有效性

### 测试2: 设备独占访问
- **目的**: 验证设备独占访问控制
- **测试项**:
  - 第一次打开成功
  - 第二次打开失败 (EBUSY)
  - 关闭后可重新打开

### 测试3: VfyPwd命令通信
- **目的**: 验证与DS532模块的实际通信
- **测试流程**:
  1. 构造VfyPwd命令包
  2. 发送到设备
  3. 接收响应包
  4. 验证响应格式
  5. 解析确认码

**预期交互**:
```
发送: EF 01 FF FF FF FF 01 00 07 13 00 00 00 00 00 1B
接收: EF 01 FF FF FF FF 07 00 03 00 XX XX
```

### 测试4: GenImg命令通信
- **目的**: 验证图像采集命令
- **注意**: 需要将手指放在传感器上
- **测试流程**: 同VfyPwd

**预期交互**:
```
发送: EF 01 FF FF FF FF 01 00 03 01 00 05
接收: EF 01 FF FF FF FF 07 00 03 XX XX XX
```

### 测试5: 超时处理
- **目的**: 验证接收超时机制
- **测试方法**: 不发送命令直接读取
- **预期结果**: 2秒后超时返回

## 🔧 故障排除

### 设备打开失败
```bash
# 检查设备节点
ls -l /dev/ds532_fp

# 检查驱动加载
lsmod | grep ds532

# 检查内核日志
dmesg | grep DS532
```

### 通信失败
```bash
# 检查UART配置
stty -F /dev/ttymxc5

# 检查硬件连接
# 使用万用表测试TX/RX/GND连接

# 检查DS532供电
# 确保3.3V供电正常
```

### 超时问题
```bash
# 检查TTY配置
stty -F /dev/ttymxc5 57600 cs8 -cstopb -parenb raw

# 查看详细日志
dmesg | grep DS532 | tail -20
```

### 常见错误码

| 确认码 | 含义 | 解决方案 |
|--------|------|----------|
| 0x00 | 成功 | 正常 |
| 0x01 | 接收包错误 | 检查数据包格式 |
| 0x02 | 无手指 | 将手指放在传感器上 |
| 0x03 | 录入失败 | 重新尝试 |
| 0x06 | 图像混乱 | 清洁传感器 |
| 0x07 | 特征点太少 | 重新采集 |
