# Stage 2 协议封装测试指南

## 📋 测试概述

Stage 2 测试验证DS532协议封装功能，包括：
- 数据包构造函数
- 校验和计算算法
- 命令封装函数
- 数据包格式验证

```bash
cd kiro_source/user
make stage2_protocol_test
```

```bash

```

## 📊 测试内容详解

### 测试1: VfyPwd命令包构造
- **目的**: 验证密码验证命令包的构造
- **输入**: 密码 0x00000000
- **预期输出**: 
  ```
  EF 01 FF FF FF FF 01 00 07 13 00 00 00 00 00 1B
  ```
- **验证项**:
  - 包头正确 (0xEF01)
  - 地址正确 (0xFFFFFFFF)
  - 包标识正确 (0x01)
  - 长度字段正确
  - 校验和正确

### 测试2: GenImg命令包构造
- **目的**: 验证采集图像命令包的构造
- **输入**: 无参数
- **预期输出**:
  ```
  EF 01 FF FF FF FF 01 00 03 01 00 05
  ```
- **验证项**: 同上

### 测试3: Img2Tz命令包构造
- **目的**: 验证生成特征命令包的构造
- **输入**: 缓冲区ID = 1
- **预期输出**:
  ```
  EF 01 FF FF FF FF 01 00 04 02 01 00 08
  ```

### 测试4: Search命令包构造
- **目的**: 验证搜索指纹命令包的构造
- **输入**: 缓冲区ID=1, 起始页=0, 页数=100
- **预期输出**:
  ```
  EF 01 FF FF FF FF 01 00 08 04 01 00 00 00 64 00 72
  ```

### 测试5: 校验和算法验证
- **目的**: 验证校验和计算的正确性
- **输入**: 测试数据 [0x01, 0x02, 0x03, 0x04, 0x05]
- **预期输出**: 0x000F (1+2+3+4+5=15)

## ✅ 成功标准

3. 包头、地址、长度字段正确

### 测试失败
1. **校验和错误**: 检查校验和计算算法
2. **包格式错误**: 检查数据包构造逻辑
3. **长度字段错误**: 检查长度计算公式

### 常见问题

**Q: 校验和计算不正确**
A: 确保校验和是从包标识开始到数据结束的累加和

**Q: 包长度字段错误**
A: 长度 = 包标识(1) + 命令码(1) + 数据长度 + 校验和(2)

**Q: 大端序/小端序问题**
A: DS532协议使用大端序，高字节在前
